# 공항주차비 MVP

국내 15개 공항의 예상 주차요금을 계산하는 정적 웹사이트입니다.

## 실행

`index.html`을 브라우저에서 직접 열거나, 이 폴더에서 정적 파일 서버를 실행하세요.

```powershell
python -m http.server 4173
```

그런 다음 `http://127.0.0.1:4173`으로 접속합니다.

## 포함 기능

- 국내 15개 공항과 공항별 주차장 선택
- 입·출차 일시와 1·3·5·7일 빠른 선택
- 금·토·일 요금 자동 반영 및 법정공휴일 수동 추가
- 소형·대형 차량 자동 분류
- 경차, 저공해 1·2·3종, 다자녀, 장애인·유공자 할인
- 공식 요금표와 저공해차 조회 페이지 연결

요금 데이터는 2026년 9월 한국공항공사와 인천국제공항공사 공식 안내를 기준으로 확인했습니다. 실제 결제 전 공식 요금표를 다시 확인해야 합니다.
